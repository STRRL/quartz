# SuperCmd - 开源 Raycast 替代品

- GitHub: https://github.com/SuperCmdLabs/SuperCmd
- 官网: https://supercmd.sh
- Discord: https://discord.gg/CsdbknHqx5

## Summary
开源 macOS launcher，目标是 Raycast + Wispr Flow + Speechify + Memory + AI 合一。

- 兼容 Raycast 扩展（有 @raycast/api shim 层）
- 按住说话语音输入、选中文字朗读
- AI: OpenAI / Claude / Ollama，ElevenLabs 语音
- 记忆: Supermemory 集成
- 技术栈: Electron + React + Vite + Swift (native)
- 看起来是小团队/个人项目，官网定位为 "premium" 但代码完全开源
- 商业模式不明确，可能是 open-core 或社区驱动
