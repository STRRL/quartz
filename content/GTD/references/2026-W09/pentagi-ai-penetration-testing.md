# PentAGI - AI Agent 渗透测试系统

vxcontrol 组织的核心项目，全自主 AI Agent 渗透测试系统。

## Key Points

- **PentAGI** (`vxcontrol/pentagi`): Go 语言，6.9k ⭐，全自主执行复杂渗透测试任务
- **SOLDR** (`vxcontrol/soldr`): 安全编排、生命周期控制、检测与响应系统
- **kali-linux-image**: 轻量 Kali Linux Docker 镜像，headless CLI 渗透工具
- 技术栈：Go 为主，依赖 langchaingo (Go 版 LangChain)
- 组织共 61 个仓库
