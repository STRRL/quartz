## 概述

开源 observability 平台，基于 OpenTelemetry，支持 traces/logs/metrics 收集、可视化、分析，带 AI 驱动诊断。

## 特点

- 基于 OpenTelemetry 标准
- 分布式 traces + logs + metrics 统一平台
- AI 驱动的诊断功能
- MCP server 集成（给 AI agent 提供 "Sentry + Git" 层）
- UI 设计不错，lapp 可参考
