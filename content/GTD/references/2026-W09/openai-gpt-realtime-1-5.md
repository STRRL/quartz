## 概述

OpenAI 发布 gpt-realtime-1.5，用于 Realtime API 语音工作流的新模型。

## 改进

- **指令遵循** — 更可靠地遵循系统提示
- **工具调用** — 语音场景下的 function calling 更稳定
- **多语言准确性** — 非英语语言的识别和生成质量提升

## 备注

值得试用，特别是中文语音场景下的表现。可以和 OpenClaw 的 voice call 插件配合测试。
